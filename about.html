About Book Explorer

Book Explorer is a beginner-friendly frontend project that demonstrates how to build a multi-page app with HTML, Tailwind CSS, and modular JavaScript.

It uses the Open Library Search API to fetch real book data, lets users search by title, and saves favorite books using localStorage so data stays available after refresh.

This project focuses on practical frontend concepts: API calls with async/await, reusable UI rendering functions, responsive layouts, and clean code organization with ES6 modules.
